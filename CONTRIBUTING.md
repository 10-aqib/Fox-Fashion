# Contributing to Fox Fashion

Thanks for your interest in improving Fox Fashion.

## Getting started

1. Fork the repository and clone it locally.
2. Create a branch for your change: `git checkout -b feature/short-description`.
3. Open `index.html` in a browser, or serve the folder with any static server.

## Guidelines

- Keep changes small and focused.
- Match the existing code style.
- Test on desktop and mobile widths before submitting.
- Write clear commit messages.

## Pull requests

Open a pull request against the default branch and describe what changed and why.
